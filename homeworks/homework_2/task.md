# N-Puzzle с IDA*

## Описание

Играта започва с квадратна дъска, състояща се от плочки с номера от `1` до `N` и една празна плочка, представена с цифрата `0`. Целта е плочките да се подредят в съответствие с номерата си.

Местенето се извършва, като на мястото на празната плочка може да се премести плочка **отгоре**, **отдолу**, **отляво** или **отдясно**.

## Задача

С помощта на алгоритъма **IDA*** и евристиката **„разстояние на Манхатън“** да се намери оптималното решение на пъзела.

### Вход

| Ред | Съдържание |
|-----|------------|
| 1 | `N` – броят на плочките с номера (`8`, `15`, `24` и т.н.) |
| 2 | `I` – индексът на позицията на нулата в решението. При `-1` се използва позицията по подразбиране – **най-долу вдясно** |
| 3+ | Подредбата на дъската |

### Изход

- **На първия ред** – дължината на оптималния път от началното до целевото състояние.
- **На следващите редове** – съответните стъпки (`left`, `right`, `up`, `down`), водещи до решението.

## Пример

**Вход:**

```
8
-1
1 2 3
4 5 6
0 7 8
```

**Изход:**

```
2
left
left
```

## Бележки

### Решимост

Не всяка конфигурация на входния пъзел е решима. Проверката за решимост може да се извърши по методите, описани на [този линк](#).

> **Внимание:** При дъски с четна страна и целево състояние, в което `0` е на първия индекс, правилото за проверка трябва да бъде модифицирано спрямо стандартния алгоритъм.

При нерешим пъзел изходът е `-1`.

### Измерване на времето

Да се предвиди опция за измерване и отпечатване на времето за намиране на решението. Подробности има в секцията [Автоматично тестване](#автоматично-тестване).

### Тестови файлове

В прикачените файлове са предоставени примерни входно-изходни конфигурации и тестови пъзели. Те служат за помощ при разработката, но **не изчерпват** всички тестове, които ще бъдат използвани при оценяването.

### Алтернативна имплементация

Имплементация на **A*** вместо **IDA*** ще бъде приета, но оценката ще бъде **намалена**.

## Автоматично тестване

Използвайте конзолния инструмент **FMI AI Judge – CLI System** ([PyPI страница](https://pypi.org/project/fmi-ai-judge/)).

Инструментът е разработен на Python, но поддържа решения на различни езици. Той **не компилира**, а стартира вече компилирани изпълними файлове или скриптове. Основните езици се разпознават автоматично. Ако вашият не е сред тях, подайте команда изрично чрез:

```bash
--exec "command {src}"
```

Необходим е **Python 3** (препоръчително в отделна виртуална среда с `venv`).

### Инсталация (еднократно)

```bash
pip install fmi-ai-judge
```

При обновяване на версията:

```bash
pip install -U fmi-ai-judge
```

### Пускане върху решението

```bash
judge run --bench path/to/solution.py
judge run --bench -p n-puzzle path/to/solution.py
```

> Автоматичното разпознаване гледа името на файла (напр. `np`, `npuzzle`, `n-puzzle`).

### Време в изхода (опционално)

Първият ред на изхода може да съдържа ваше измерване в милисекунди:

```
# TIMES_MS: alg=<милисекунди>
```

> Това време се включва в отчета **само** ако стартирате с `--bench`.

### Тестове само за време

Някои по-големи тестове са само за производителност. При тях инструментът стартира решението с променлива на средата:

```bash
FMI_TIME_ONLY=1
```

Ако засечете `FMI_TIME_ONLY=1`, може да пропуснете отпечатването на пълното решение и по желание да изведете само реда с измереното време (във формата по-горе). За **всички останали** тестове изходът трябва да е пълен и коректен.
