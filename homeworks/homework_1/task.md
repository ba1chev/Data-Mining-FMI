# Задача 1 — Frog Leap Puzzle

## Описание

Играта разполага с игрално поле от **2N + 1** полета. В началото:

- В **най-левите N** полета има жаби, гледащи **надясно** (`>`)
- В **средното** поле има **празно** място (`_`)
- В **най-десните N** полета има жаби, гледащи **наляво** (`<`)

**Целта** е жабите да си разменят местата — да се стигне до противоположната конфигурация.

## Правила

- Всяка жаба може да се движи **само в посоката, в която гледа**.
- Всяка жаба може да:
  - **Скочи на свободното място** директно пред себе си (1 стъпка), или
  - **Прескочи една жаба**, за да отиде на празното място пред нея (2 стъпки).

## Вход

```
N
```

> `N` — броят на жабите, гледащи в **една** посока.

## Изход

Всички конфигурации (включително началната), **през които се минава** за да се стигне от началното до финалното състояние.

## Пример

**Вход:**
```
2
```

**Изход:**
```
>>_<<
>_><<
><>_<
><><_
><_<>
_<><>
<_><>
<<>_>
<<_>>
```

## Изисквания за производителност

- Решението трябва да работи за `N = 20` за **под 1 секунда**.

> **Бележка:** Задачата може да бъде решена и за линейно (O(N)) **стъпки**, използвайки подход, основан на правила.

## Автоматично тестване

Използвайте конзолния инструмент **FMI AI Judge CLI**:
- Страница: https://pypi.org/project/fmi-ai-judge/

Инструментът поддържа решения на различни езици. Той не компилира, а стартира вече компилирани изпълними файлове или скриптове.

### Инсталация (еднократно)

```bash
pip install fmi-ai-judge
```

> При обновяване: `pip install -U fmi-ai-judge`

### Стартиране

```bash
judge run --bench path/to/solution.cpp
judge run --bench -p frog-leap path/to/solution.cpp
```

> Автоматичното разпознаване гледа името на файла (напр. `flp`, `frog-leap`).

### Опционален ред с измерено време

Първият ред на изхода може да съдържа измерване в милисекунди:

```
# TIMES_MS: alg=<милисекунди>
```

> Времето се включва в отчета само при стартиране с `--bench`.

### Тестове само за производителност

При по-големи тестове инструментът стартира решението с:

```
FMI_TIME_ONLY=1
```

При засечен `FMI_TIME_ONLY=1` може да пропуснете пълния изход и да изведете само реда с измереното време.
