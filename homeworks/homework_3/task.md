# Домашно 3 — N-Queens с Min-Conflicts

## Описание

Задачата (N-Queens) се състои в това да се разположат `N` царици на квадратна шахматна дъска `N×N`, така че да не се бият – т.е. да няма повече от една царица в един и същи ред, колона или диагонал.

Да се използва алгоритъмът **Min-Conflicts** за намиране на решение.

## Вход

Цяло число `N` – броят на цариците (`N ≥ 1`).

## Изход

Масив с позициите на цариците, където индексът отговаря на колоната, а стойността на реда.

Пример: за `N = 4` възможен изход е `[1, 3, 0, 2]`.

## Пример

**Вход** (при автоматично тестване):

```
4
```

**Изход** (при автоматично тестване):

```
[2, 0, 3, 1]
```

## Бележки

- Задачата няма решение за `N ∈ {2, 3}`. В тези случаи изходът трябва да е `-1`.
- Да се предвиди опция за измерване и отпечатване на времето за намиране на решението (повече подробности са налични в секцията [„Автоматично тестване“](#автоматично-тестване)).
- При големи стойности на `N` не е необходимо да се извежда решението. В тези случаи може да се отпечата само времето за изпълнение на алгоритъма (повече подробности са налични в секцията [„Автоматично тестване“](#автоматично-тестване)).
- Да се поддържа опция за принтиране на дъската (може и чрез флаг или хардкодната настройка):
  - царица: `*`;
  - празна клетка: `_`;
  - всеки ред се извежда на нов ред, клетките се разделят с интервал.

  Примерно извеждане за `N = 4`:

  ```
  _ * _ _
  _ _ _ *
  * _ _ _
  _ _ * _
  ```

- Алгоритъмът трябва да решава случая `N = 10 000` (±10) за **под 1 секунда**.

## Автоматично тестване

Използвайте конзолния инструмент **FMI AI Judge – CLI System** (страница: https://pypi.org/project/fmi-ai-judge/).

Инструментът е разработен на Python, но поддържа решения на различни езици. Той не компилира, а стартира вече компилирани изпълними файлове или скриптове. Основните езици се разпознават автоматично. Ако вашият не е сред тях, подайте команда изрично чрез:

```bash
--exec "command {src}"
```

Необходим е Python 3 (препоръчително е отделна виртуална среда с `venv`).

### Инсталация (еднократно)

```bash
pip install fmi-ai-judge
```

При обновяване на версията изпълнете:

```bash
pip install -U fmi-ai-judge
```

### Стартиране

```bash
judge run --bench path/to/solution.py
judge run --bench -p n-queens path/to/solution.py
```

> Автоматичното разпознаване гледа името на файла (напр. `nq`, `nqueens`, `n-queens`).

### Време в изхода (опционално)

Първият ред може да съдържа ваше измерване (в милисекунди):

```
# TIMES_MS: alg=<милисекунди>
```

> Това време се включва в отчета само ако стартирате с `--bench`.

### Тестове само за време

Някои по-големи тестове са само за производителност (без пълен изход). При тях инструментът стартира решението с променлива на средата:

```bash
FMI_TIME_ONLY=1
```

Ако засечете `FMI_TIME_ONLY=1`, може да пропуснете печата на пълното решение и по желание да изведете само ред с измереното време (формата по-горе). За останалите тестове изходът трябва да е пълен и коректен.
